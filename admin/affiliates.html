アフィリエイト管理

申し込みリンク・バナー・報酬情報を一元管理。「保存」ボタン1つでGitHubに反映されます。

リポジトリ情報

GitHubに直接保存するために必要な情報を入力してください。ここで入力した内容はこのブラウザのlocalStorageにのみ保存され、GitHubにはアップロードされません。

Personal Access Token（PAT）

GitHubの設定 → Developer settings → Personal access tokens → Tokens (classic) から発行してください。スコープは repo だけで大丈夫です。
トークンはこのブラウザのlocalStorageにのみ保存されます。GitHubには送信されません。

発行手順：GitHub右上アイコン → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
Expiration: No expiration、スコープ: repo にチェック → Generate token

申し込みURL・バナーを入力して「GitHubに保存」を押すと affiliates.json が更新されます。
